# Evara-UI

Evara is an open-source, highly scalable UI library and design system. It provides modular, consistent, and testable components with built-in support for performance optimization, SEO, analytics, and backend-driven workflows.
Let's begin by setting up the core, it's shared stuff, not framework specific, so because of this, it's only typescript in the core.
Read: @AGENTS.md and docs.
