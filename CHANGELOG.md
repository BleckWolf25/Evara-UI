# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-07-08

### Added

- Modular, framework-agnostic headless state controllers inside `@bleckwolf25/core`.
- Native Custom Elements wrapper implementations for framework-agnostic web component support.
- Fully typed wrappers and component lifecycle adapters for React, Vue, and Svelte.
- Centralized CSS styling variables, themes, and layouts within `@bleckwolf25/styles`.
- Integrated Build and bundle packaging configs via `tsup` targeting ESM, CJS, and DTS.
- Interactive showcase sandboxes for Vite-React, Next.js (SSR), Vite-Vue, Nuxt.js (SSR), Svelte, Web Components, and Vanilla HTML.
- Automated pipeline setups for PR validation, code format checks, unit tests, and automated releases via changesets.
- Complete documentation website setup using VitePress.
