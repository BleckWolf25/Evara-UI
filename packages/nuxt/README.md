# @bleckwolf25/nuxt

> Nuxt 3 module for automatic integration of Evara UI components, styles, and composables.

`@bleckwolf25/nuxt` auto-imports Evara UI components, composable state hooks, and stylesheets zero-config in your Nuxt 3 application.

## 📦 Installation

```bash
npm install @bleckwolf25/nuxt @bleckwolf25/vue @bleckwolf25/styles
# or
pnpm add @bleckwolf25/nuxt @bleckwolf25/vue @bleckwolf25/styles
```

## 🚀 Nuxt Configuration

Add `@bleckwolf25/nuxt` to the `modules` array in `nuxt.config.ts`:

```typescript
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['@bleckwolf25/nuxt']
})
```
