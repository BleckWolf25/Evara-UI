# Spinner Component

The Spinner component displays an animated loading indicator for asynchronous operations.

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Spinner size scale |
| `color` | `'primary' \| 'secondary' \| 'white'` | `'primary'` | Spinner color |

## Code Example

```tsx
<Spinner size="md" color="primary" />
```
