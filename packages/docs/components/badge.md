# Badge Component

The Badge component highlights status, numerical counts, or category labels.

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `color` | `'primary' \| 'secondary' \| 'success' \| 'warning' \| 'danger' \| 'info' \| 'error' \| 'default'` | `'primary'` | Color token variant |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Badge size scale |
| `position` | `'top-right' \| 'top-left' \| 'bottom-right' \| 'bottom-left'` | `undefined` | Optional overlay position |

## Code Example

```tsx
<Badge color="success" size="sm">New Release</Badge>
```
