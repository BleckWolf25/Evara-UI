# Separator Component

The Separator component visually or semantically divides content items horizontally or vertically.

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Divider direction |
| `decorative` | `boolean` | `true` | If true, element is hidden from accessibility tree |

## Code Example

```tsx
<Separator orientation="horizontal" />
```
