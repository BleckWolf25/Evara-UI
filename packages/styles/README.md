# @bleckwolf25/styles

> Centralized vanilla CSS design tokens, reset stylesheets, and theme palettes for Evara UI.

`@bleckwolf25/styles` provides framework-agnostic CSS variables for color tokens, spacing, typography, shadows, border radius, motion transitions, and theme palettes.

## 📦 Installation

```bash
npm install @bleckwolf25/styles
# or
pnpm add @bleckwolf25/styles
```

## 🚀 Usage

### Global Import

Import the full combined design system bundle:

```css
@import '@bleckwolf25/styles/dist/index.css';
```

Or in JavaScript/TypeScript:

```typescript
import '@bleckwolf25/styles/dist/index.css'
```

### Granular Token Imports

```css
@import '@bleckwolf25/styles/dist/tokens/colors.css';
@import '@bleckwolf25/styles/dist/tokens/spacing.css';
@import '@bleckwolf25/styles/dist/tokens/typography.css';
@import '@bleckwolf25/styles/dist/themes/dark.css';
```
